엑셀 자동 재정렬 툴

① 출력 폼 첨부 → ② 재구성 대상 엑셀 첨부 → ③ 필터 조건 설정(유지/제거) → ④ 컬럼 매핑 → ⑤ 실행 및 다운로드. 모든 처리는 브라우저 안에서만 이루어지며 파일은 외부로 전송되지 않습니다.

1
출력 폼 첨부
최종 결과물의 컬럼 구성으로 사용할 엑셀 양식을 첨부하세요. 이 파일의 최상단 헤더 행이 결과 컬럼이 됩니다.
📄
출력 폼 엑셀파일을 첨부해주세요
클릭하여 선택하거나, 파일을 이곳에 끌어다 놓으세요 (.xlsx만 지원 — 서식 보존을 위해 .xls는 .xlsx로 변환 후 첨부해주세요)

감지된 출력 컬럼 (총 0개)

2
재구성 대상 엑셀 첨부
재정렬할 원본 데이터 파일을 첨부하세요. 최상단 헤더 행의 컬럼들을 불러와 필터/매핑에 사용합니다.
📎
재구성 대상 엑셀파일을 첨부해주세요
클릭하여 선택하거나, 파일을 이곳에 끌어다 놓으세요 (.xlsx만 지원)

감지된 원본 컬럼 (총 0개) · 데이터 0행

3
필터 조건 설정
원본 컬럼을 선택하고, 그 컬럼에 있는 내용(값)을 입력해 해당 행을 유지할지 제거할지 정하세요. 값은 쉼표로 여러 개 입력할 수 있습니다(OR 조건). 조건은 위에서부터 순서대로 적용됩니다.
조건을 추가하지 않으면 필터링 없이 전체 행이 사용됩니다.
4
컬럼 매핑
출력 폼의 각 컬럼에 채워 넣을 원본 컬럼을 선택하세요. 컬럼명이 일치하면 자동으로 매핑됩니다.
출력 컬럼원본 컬럼
💾 필터 조건 · 컬럼 매핑 설정 저장/불러오기
자주 쓰는 조건과 매핑을 이름 붙여 저장해두면, 다음에 새 파일을 첨부했을 때 바로 불러와 적용할 수 있습니다. 브라우저(이 PC)에 저장되며, 파일로 내보내 다른 PC나 동료와 공유할 수도 있습니다.

5
실행 및 다운로드
조건과 매핑을 적용해 출력 폼에 데이터를 채웁니다. 출력 폼의 기존 서식은 최대한 유지됩니다.
